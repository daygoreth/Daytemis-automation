Tutoriales en video

Cómo conseguir tu API de Odoo

Toma 5 minutos. Si te trabas, escríbenos y lo hacemos juntos.

▶

Video: Crear usuario dedicado

Reemplaza este bloque con un <iframe> de YouTube/Loom
Paso 1

Crea un usuario dedicado para Artemiz

Esto te permite cortar el acceso fácilmente después, sin tocar tu cuenta personal.

  1. Entra a Odoo como administrador.
  2. Ajustes → Usuarios y compañías → Usuarios → Crear.
  3. Nombre: Integración Artemiz.
  4. Permisos: Ventas (Vendedor), Inventario (Usuario), Contactos (Lectura/escritura), POS si aplica.
▶

Video: Activar modo desarrollador

Reemplaza este bloque con un <iframe> de YouTube/Loom
Paso 2

Activa el modo desarrollador

Sin este modo no aparece la opción para generar API Keys. No es peligroso, es solo una vista extra.

  1. Ve a Ajustes.
  2. Baja hasta el final de la página.
  3. Click en Activar el modo desarrollador.
▶

Video: Generar la API Key

Reemplaza este bloque con un <iframe> de YouTube/Loom
Paso 3

Genera la API Key

Esta es la "llave" que Artemiz usará para leer tu catálogo y registrar ventas.

  1. Cierra sesión y entra con el usuario "Integración Artemiz".
  2. Tu nombre arriba a la derecha → Mi perfil.
  3. Pestaña Cuenta de seguridad → Developer API Keys.
  4. Click en Nueva clave de API → ponle un nombre → Generar.
  5. ⚠️ Cópiala ya, solo se muestra una vez.
▶

Video: Encontrar URL y base de datos

Reemplaza este bloque con un <iframe> de YouTube/Loom
Paso 4

Identifica tu URL y base de datos

Son los dos datos que faltan para conectarnos.

  1. URL: es la dirección de tu Odoo, ej. https://miempresa.odoo.com.
  2. Base de datos: normalmente es la parte antes de .odoo.com. Si no, búscala en Ajustes → Información.

Mándanos estos 4 datos

⚠️ Nunca compartas tu contraseña personal de Odoo. Solo la API Key.

Preguntas frecuentes

Lo que más nos preguntan

¿Esto le da acceso total a mi Odoo a Artemiz?

No. Solo accedemos con los permisos del usuario "Integración Artemiz" que tú creas. Recomendamos darle solo: ventas, inventario y contactos. Nada más.

¿Puedo cortar el acceso cuando quiera?

Sí, en cualquier momento. Solo borras la API Key desde el perfil del usuario, o desactivas al usuario completo. Tú tienes el control.

Mi Odoo es Community (gratis), ¿igual funciona?

Sí. La integración funciona con Community y Enterprise, desde la versión 14 en adelante.

¿Qué pasa si Odoo se cae?

Artemiz mantiene una caché de tu catálogo. Si Odoo no responde, sigues vendiendo por WhatsApp y las ventas se sincronizan apenas vuelve.

¿Necesito instalar algo en mi Odoo?

No es obligatorio. La integración base funciona solo con la API estándar de Odoo. Si quieres notificaciones en tiempo real (cambios de precio o stock al instante), instalamos un módulo pequeño y opcional.

¿Puedo seguir vendiendo desde mi POS de Odoo normal?

Por supuesto. Artemiz no reemplaza tu POS. Es una capa adicional para vender por WhatsApp. Tu tienda física sigue operando exactamente igual.

¿Cuánto demora la implementación?

Demo funcional con tu propio catálogo en 1–2 días. Implementación completa (ventas, IA, automatizaciones) entre 5 y 10 días según el alcance.

¿Listo para que tu Odoo venda por WhatsApp?

Coordinamos una llamada corta, revisamos tu Odoo y te armamos la cotización exacta. Sin compromiso.
